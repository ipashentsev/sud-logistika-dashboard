# Дашборд логиста: участки 1-87

Статический дашборд для логиста выездов по участкам.

## Структура
- `index.html` - интерфейс
- `styles.css` - стили
- `app.js` - логика
- `data/spisok_1_87_kupchino.csv` - таблица участков
- `data/points_1_87.json` - координаты и адреса точек карты
- `data/uchastki.json` - исходные данные по участкам

## Локальный запуск
```bash
cd /home/team-05/project-mirovye-sudi-logistika/data/dashboard
python3 -m http.server 8080
```
Открыть: `http://127.0.0.1:8080/`

## Публикация
GitHub Pages из `main` ветки, папка `/(root)`.

## Текущее поведение
- поиск по номеру/адресу;
- выбор участка в таблице и на карте;
- подсветка выбранного участка;
- маршрут по дорогам от м. Купчино до выбранного участка;
- кнопка перехода в Яндекс.Карты с предзаполненным маршрутом.
